# Student Database Management System

This is a simple Student Database Management System developed using C.

The project is mainly created to practice working with structures, functions, file handling, and basic database operations in C. Student details are stored in a file so that the data can be used again when the program is opened.

## Features

- Add student details
- View student records
- Search for a student
- Update student details
- Delete student records
- Store student data using file handling

## Technologies Used

- C Programming
- GCC Compiler
- File Handling
- Structures
- Functions
- Git and GitHub
